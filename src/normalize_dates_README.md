# 日付正規化スクリプト

## 概要
`normalize_dates.py` は、データベース内の既存のトランザクション日付を `YYYY-MM-DD` 形式に正規化するためのスクリプトです。

## 使用方法

### 1. スクリプトの実行
```bash
cd src
python normalize_dates.py
```

### 2. 実行内容
- データベースの自動バックアップを作成
- 既存の全トランザクションの日付を確認
- 異なる形式の日付を `YYYY-MM-DD` 形式に変換
- 変換前後のサンプルと統計情報を表示

### 3. サポートされる日付形式
- `YYYY-MM-DD` (既に正規化済み)
- `YYYY/MM/DD`
- `YYYY-MM-DD HH:MM:SS`
- `YYYY-MM-DDTHH:MM:SS`
- `DD-MM-YYYY` (ヨーロッパ形式)
- `DD/MM/YYYY`
- `MM-DD-YYYY` (米国形式)
- `MM/DD/YYYY`
- Unixタイムスタンプ
- その他の一般的な形式

### 4. 注意事項
- 実行前に必ずバックアップが作成されます
- 変更がない場合、バックアップは自動的に削除されます
- エラーが発生した場合、バックアップから復元できます

## 堅牢なフィルタリング

データベースの日付が正規化されていなくても、`src/db.py` で使用されている SQLite の `DATE()` 関数により、様々な形式の日付でフィルタリングが可能です。

しかし、最高のパフォーマンスとデータの一貫性のために、このスクリプトで日付を正規化することをお勧めします。
