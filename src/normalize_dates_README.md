# 日付正規化スクリプト

## 概要
`normalize_dates.py` は、データベース内の既存のトランザクション日付を `YYYY-MM-DD` 形式に正規化するためのスクリプトです。

## 使用方法

### 1. スクリプトの実行
```bash
cd src
python normalize_dates.py
```

### 2. 実行内容
- タイムスタンプ付きのデータベースバックアップを自動作成
- 既存の全トランザクションの日付を確認
- 異なる形式の日付を `YYYY-MM-DD` 形式に変換
- パフォーマンス向上のためバッチ更新を使用
- 変換前後のサンプルと統計情報を表示
- タイムスタンプ付きの詳細なログ出力

### 3. サポートされる日付形式
- `YYYY-MM-DD` (既に正規化済み)
- `YYYY/MM/DD`
- `YYYY-MM-DD HH:MM:SS`
- `YYYY-MM-DDTHH:MM:SS`
- `DD-MM-YYYY` (ヨーロッパ形式)
- `DD/MM/YYYY`
- `MM-DD-YYYY` (米国形式)
- `MM/DD/YYYY`
- Unixタイムスタンプ
- その他の一般的な形式

### 4. 改善された機能
- **バッチ更新**: すべての更新を1つのトランザクションで実行し、パフォーマンスを向上
- **エラーハンドリング**: `ValueError`（日付形式エラー）と一般的な例外を区別して処理
- **タイムスタンプ付きバックアップ**: `users.db.backup_20250604_123456` のような形式
- **標準ログ機能**: Pythonの標準`logging`モジュールを使用
- **将来日付の検出**: 未来の日付が検出された場合に警告

### 5. 注意事項
- 実行前に必ずタイムスタンプ付きバックアップが作成されます
- 変更がない場合、バックアップは自動的に削除されます
- エラーが発生した場合、バックアップから復元できます
- バッチ更新が失敗した場合、すべての変更がロールバックされます

## パフォーマンスの考慮事項

データベースの日付が正規化されていなくても、`src/db.py` で使用されている SQLite の `DATE()` 関数により、様々な形式の日付でフィルタリングが可能です。

ただし、`DATE()` 関数の使用はインデックスの効率的な利用を妨げる可能性があります。最高のパフォーマンスとデータの一貫性のために、このスクリプトで日付を正規化し、直接文字列比較を使用することをお勧めします。
